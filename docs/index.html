Coin Inventory Service

An investment coin portfolio service for tracking acquisition cost, live metal value, and profit or loss per coin. It stores the collection in Redis, values gold with XAUS spot prices, exposes REST endpoints, and gives AI assistants the same capabilities through Symfony MCP tools.

Investment ledger

A small portfolio engine for physical gold coins.

The service keeps the operational details boring on purpose: deterministic coin records, cached market data, transparent calculation rules, and a clean report that answers the investor question first.

01

Coin Registry

Tracks purchase price, currency, purity, weight, country, and purchase date for each coin.

02

XAUS Valuation

Fetches gold spot price per gram and adjusts it by karat before multiplying by pure metal weight.

03

Profitability

Answers whether the portfolio is in profit and shows the delta for every coin.

04

MCP Tools

Exposes the same application use cases to AI clients through Symfony MCP Bundle.

Profitability endpoint

Know which coins are up, down, and by how much.

The report compares purchase value with live metal value. Totals are grouped by currency, because each coin is valued in its purchase currency.

Valuation flow

From coin specs to portfolio signal.

Every report follows the same path: get the XAUS gram price, adjust it by karat, multiply by pure metal weight, then compare it with the original purchase price.

Formula

spotGram * karat / 24 * pureMetalWeight

Pure metal

weight * purity / 100

Cache

Market requests are cached through Guzzle for one hour.

Currency

Each coin is valued in the same currency it was purchased in.

Agent interface

REST for applications, MCP for assistants.

Controllers and MCP tools share the same application use cases, so automation and human-facing clients operate against one business model.

coins_inventory_list

Lists coins with current calculated metal values.

coins_inventory_place

Adds a coin using the same validation rules as the REST API.

coins_inventory_profitability

Returns per-coin and portfolio profit/loss grouped by currency.
